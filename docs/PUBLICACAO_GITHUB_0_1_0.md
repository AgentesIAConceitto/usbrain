# Publicacao GitHub 0.1.0

Este documento existe para executar a primeira publicacao manual do repositorio e da release `0.1.0` com o minimo de friccao.

## 1. Criar o repositorio

1. Criar o repositorio publico `usbrain`.
2. Definir homepage como `https://usbrain.org`.
3. Aplicar descricao curta definida em `docs/GITHUB_REPOSITORY_PROFILE.md`.
4. Aplicar os topics recomendados.

## 2. Enviar o codigo

1. Revisar arquivos sensiveis antes do push.
2. Confirmar que `cache/`, bundles e artefatos locais nao serao publicados.
3. Publicar a branch principal.

## 3. Revisar o perfil publico

1. Conferir `README.md`.
2. Conferir `LICENSE`.
3. Conferir `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` e `SECURITY.md`.
4. Conferir pasta `docs/`.

## 4. Criar a release

1. Criar a tag `v0.1.0`.
2. Criar uma GitHub Release com titulo `USBRAIN 0.1.0`.
3. Usar o texto de `docs/RELEASE_0_1_0_GITHUB.md`.
4. Anexar o bundle do `USBRAIN Builder`.
5. Anexar `SHA256SUMS.txt`, quando aplicavel.

## 5. Verificacoes finais

1. Validar links do `README.md`.
2. Validar links da pasta `docs/`.
3. Conferir que a release aponta para a homepage correta.
4. Conferir que a descricao publica nao contradiz o estado atual do produto.

## 6. Depois da publicacao

1. Abrir o backlog publico inicial.
2. Criar milestones para `PACK authoring`, `model catalog` e `Hub`.
3. Publicar a pagina inicial em `usbrain.org`.
4. Vincular o site, o repositorio e a release entre si.
