# Manifesto USBRAIN

## Tese

IA pessoal nao deve depender de infraestrutura opaca, conexao permanente nem hardware premium para ser util.

O USBRAIN existe para tornar agentes inteligentes:

- portateis;
- privados;
- adaptativos ao hardware real;
- especializados por contexto;
- distribuidos de forma aberta.

## O que defendemos

- `offline-first` como base real do produto;
- `CPU-only` como garantia minima de utilidade;
- GUI desktop real para criacao do USBRAIN;
- multiplos modelos locais quando isso fizer sentido;
- packs especialistas como parte central do ecossistema;
- catalogo vivo de modelos para evitar obsolescencia;
- contribuicao comunitaria como motor de evolucao.

## O que rejeitamos

- dependencia obrigatoria de cloud;
- experiencia centrada em terminal para o usuario final;
- acoplamento fraco entre Builder e Runtime;
- simulacoes que escondem falhas reais do produto;
- publicacao open source sem documentacao, governanca e criterio minimo.

## O produto

O USBRAIN nao e apenas um pendrive com uma LLM.

O USBRAIN e uma plataforma composta por:

- `Builder`: cria, valida e prepara releases;
- `Runtime`: executa o agente e se adapta ao hardware;
- `PACKs`: adicionam conhecimento, comportamento e ferramentas;
- `Hub`: organiza a camada comunitaria;
- `Catalogo de Modelos`: acompanha a evolucao do ecossistema open source.

## Para quem estamos construindo

- pessoas que querem um agente pessoal privado e portatil;
- profissionais que precisam de especializacao por dominio;
- criadores que desejam montar USBRAINs para terceiros;
- comunidades que pretendem empacotar conhecimento em PACKs.

## Regra de qualidade

Cada entrega do USBRAIN deve aproximar o projeto de uma plataforma open source coerente, distribuivel e realmente utilizavel por pessoas nao tecnicas.
