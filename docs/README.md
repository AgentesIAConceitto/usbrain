# USBRAIN Docs

Esta pasta concentra a documentacao publica inicial do USBRAIN para leitura rapida por usuarios, contribuidores e futuros mantenedores.

Se voce esta chegando agora, comece por estes documentos:

- `MANIFESTO_USBRAIN.md`: tese curta do projeto e seus principios.
- `ECOSSISTEMA_USBRAIN.md`: mapa resumido de Builder, Runtime, PACKs, Hub e Catalogo de Modelos.
- `CHECKLIST_RELEASE_PUBLICA.md`: lista operacional para abrir a primeira release publica do repositorio e do Builder.
- `RELEASE_0_1_0_GITHUB.md`: texto base pronto para a primeira GitHub Release.
- `GITHUB_REPOSITORY_PROFILE.md`: descricao curta, topics e homepage recomendados.
- `PUBLICACAO_GITHUB_0_1_0.md`: playbook manual da publicacao inicial.
