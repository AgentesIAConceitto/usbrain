# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-29

### Added

- Functional `USBRAIN Builder` desktop base in `Tauri + Rust`.
- Real build planning and manifest generation for USB targets.
- Assembly, validation, smoke test, runtime probe, E2E probe and full local LLM probe.
- Consolidated readiness report and final distribution gate.
- Release package generation with `SHA256SUMS.txt`, GitHub release notes and `usbrain-release-summary.json`.
- Root open source metadata including `LICENSE`, `.gitignore` and updated public documentation.
